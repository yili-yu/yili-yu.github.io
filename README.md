# yili 境内原型

公开站第二阶段原型。根目录是鸟居外的门槛，`/shrine/` 才是神社境内；场景中的物件承担导航，`/index/` 是直接查找的可靠后备。

## 本地预览

```powershell
python -m http.server 8081 --directory E:\YU\yiliyu-sites\yili-shrine-site
```

然后访问 `http://localhost:8081/`。

## 已实现

- 原创鸟居入口与暮色神社主景
- 根目录根据上海日期与时段显示今日状态，并记住是否来过
- 桌、信箱、赛钱箱、扫帚、仓库、本殿和后山热点
- 独立、无机关的正式文字索引
- 手机端保留完整场景，可横向行走；文字索引作为可选案内
- 场景物件直接承担链接，平时不显示任务点式标签
- 五个可进入的房间和一个隐藏页
- 独立 404 页面
- 继承现有 yiliyu.com 的公开边界、站点元数据和 GitHub Pages 部署外壳

# yili｜个人学术主页（GitHub Pages 版）

这是可以直接部署到 GitHub Pages 的纯静态网站，不需要安装程序、运行构建命令或配置数据库。

## 使用方法

1. 将压缩包里的全部文件和文件夹上传到 `yili-yu.github.io` 仓库的 `main` 分支根目录。
2. 保留 `CNAME` 文件，其内容已经设置为 `yiliyu.com`。
3. 在 GitHub 仓库的 Settings → Pages 中选择从 `main` 分支的 `/ (root)` 发布。
4. DNS 检查通过后，启用“强制执行 HTTPS”。

上传时要保留文件夹结构，并确保 `index.html` 位于仓库最外层，而不是多套一层文件夹。
